# サイバー・ダークモダン デザインシステム規約

うなぎちゃん公式サイトのビジュアルアイデンティティは「ダークモダン / サイバー（黒基調・ネオンアクセントのエンジニア・クリエイター向け）」です。
新しいページやコンポーネントを追加する際は、以下のCSS変数とクラス命名規則に必ず従ってください。

---

## 1. デザイントークン (CSS Variables)

`src/styles/global.css` に定義されている以下の変数を使用すること：

| 変数名 | カラー値 | 用途 |
| :--- | :--- | :--- |
| `--bg-main` | `#07090e` | サイト全体の一番深い背景色 |
| `--bg-surface` | `rgba(14, 20, 34, 0.75)` | カードやモーダルの半透明背景 |
| `--cyan` | `#00f0ff` | プライマリアクセント、リンク、重要テキスト |
| `--purple` | `#8b5cf6` | セカンダリアクセント、グラデーション中間色 |
| `--pink` | `#ec4899` | 強調タグ、バッジ、ホバーアクセント |
| `--text-main` | `#f8fafc` | 見出し、本文（高コントラスト） |
| `--text-secondary` | `#94a3b8` | サブテキスト、説明文 |
| `--text-muted` | `#64748b` | 日付、フッター、補足 |

---

## 2. 共通UIコンポーネントクラス

新しくHTML/Astroコンポーネントを作成する際は、既存のユーティリティクラスを組み合わせて構成すること：

- `.cyber-card`: グラスモーフィズム＋上部微細光彩＋ホバーリフト（`translateY(-3px)`）
- `.cyber-btn`: ボタンベース
  - `.cyber-btn-primary`: ネオングロー＋シアン/パープルグラデーション
  - `.cyber-btn-secondary`: 半透明ブラック＋微細ボーダー
- `.cyber-badge`: ネオンピルバッジ（`.pink`, `.purple` バリエーション）
- `.gradient-text`: シアン〜パープル〜ピンクの美しいグラデーション文字

---

## 3. レスポンシブ & アクセシビリティ
- モバイルファーストで設計し、`max-width: 600px`, `min-width: 768px`, `min-width: 900px` のブレークポイントで最適化する。
- ボタン・タップターゲットは最低でも 44×44px を確保し、スマホ操作性を損なわないこと。
- 背景と文字のコントラスト比は WCAG AA 基準（4.5:1以上）を常に保つこと。
