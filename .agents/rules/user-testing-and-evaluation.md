# テスト・評価方針規約 (User Testing & AI Evaluation Policy)

本プロジェクトにおけるテストおよび検収の運用ルールです。
Antigravity Gemini（エージェント）は、以下の規約を厳格に遵守してください。

---

## 1. テスト実行に関する絶対禁止事項
- **AI（エージェント）による自動・手動ブラウザテスト、UI操作テスト、E2Eテストの自律実行は禁止とする。**
- 実際の画面描画やブラウザ上の操作確認・挙動テストは、**すべてユーザー自身が直接実施する**。
- AIの役割は「コードの実装」と「静的ビルド（`npm run build` によるシンタックス/型エラーの検証）」までに留める。

---

## 2. 実装完了時の必須アクション：「実装に対する評価リスト」の提示
AIは実装・改修作業を終えた際、必ず**ユーザーが確認・検収するための「評価リスト（受入検証チェックリスト）」**を作成し、回答の末尾で提示すること。

### 評価リストに含めるべき項目：
1. **確認対象のURL・画面パス**（ローカル開発サーバー上のURL）
2. **デザイン・見た目の確認ポイント**（レイアウト崩れ、カラー、フォント、装飾等）
3. **リンク・操作系の確認ポイント**（ボタンの遷移先、外部リンクの属性、フォーム・トグルの挙動）
4. **AdSense・SEO・要件定義の充足確認**（メタタグ、必須記載事項、固定ページの有無）
5. **合否判定用チェックボックス（`[ ]`）**
